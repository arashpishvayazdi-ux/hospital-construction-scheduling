# 150-Bed Hospital Construction Scheduling & Project Control

## About The Project
This repository contains the comprehensive baseline and recovery schedule for a 150-bed hospital construction project. The project involved resuming work on a partially completed site, requiring a detailed assessment of the current progress (with varying completion percentages across different tasks, such as MEP and wiring) and restructuring the remaining work.

To accelerate the operational handover to the client, the project delivery was strategically divided into **3 distinct phases**. 

## Key Features & Methodologies
* **Recovery Scheduling:** Adapted and updated the schedule for a resumed project, accurately reflecting the physical progress of partially completed tasks.
* **Phased Delivery Strategy:** Restructured the project timeline to deliver the hospital in 3 functional phases, ensuring earlier utilization of key facilities.
* **Advanced MSP Techniques:** Implemented an innovative approach using **Group Filtering** in MS Project to dynamically isolate, visualize, and manage the 3 delivery phases without disrupting the critical path.
* **Scope Management:** Focused the scheduling efforts on Blocks A, B, and C, while effectively excluding Block D (which was already in the final facade stage).

## Tools & Technologies
* **Microsoft Project (MSP):** WBS creation, critical path method (CPM), resource allocation, and progress tracking.
